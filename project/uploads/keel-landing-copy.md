## 3 · Built for now, not ported from then

**Headline:**
Not a copy of the old software. The version that couldn't exist until now.

**Pillar one — built on today's assumptions:**
Every Kit is built the way you'd build it today, with none of the decade of legacy debt the incumbents carry. The difference isn't a longer feature list — it's that the manual busywork their architecture forces on people is simply gone.

*Before:* A CS manager combs usage, tickets, and login data across dozens of accounts to guess which customers are slipping — then hand-writes each check-in.
*After:* The system watches every account continuously, surfaces the ones actually at risk and why, and drafts the outreach. The manager just approves.

**Pillar two — and it runs itself:**
Once it's live, AI agents run support and operations by default — the team you'd otherwise have to hire. So one person can operate what used to take a department.

- A support agent resolves a customer's question and escalates the genuine edge case to you, with the full context attached.
- An onboarding agent walks a new signup through setup while you sleep.
- An ops agent flags an anomaly before it becomes an outage.

**Honesty line:**
Agents handle the routine and hand the rest to you — with context, and nothing in the dark, because it's all logged. This isn't an autonomous-employee fantasy. It's the staff you didn't have to hire, knowing when to ask you.

**Closing grace note:**
And it gets more capable as AI does.

## 4 · See it run before you spend a cent

**Headline:**
See it run before you spend a cent.

**Subhead:**
Watch the agents work, live — and see exactly what every Kit had to pass.

**Sandbox framing:**
This isn't a video. Trigger it and watch a real scenario play out: an account's usage quietly drops, the agent catches the signal, pulls together the context — who, why, the history — and drafts a tailored re-engagement email. And when the situation needs a human call, it hands the account to you with a summary instead of sending. You can see it think, step by step, and you can see it know its limits.

**The audit:**
Every Kit has to pass the same automated architecture audit before it's ever listed — security, responsiveness and accessibility, and AI-runtime reliability. The marketplace itself is the filter. The criteria are open for you to inspect; this is our standard applied to everything, not a badge we award ourselves.

**Why it costs a fraction (the honest answer):**
AI makes a Kit cheap to *build* — but AI alone would produce something that breaks in production. That's exactly why every Kit is built by an experienced hand and has to pass the audit before you can buy it. Cheap to build, made real by expertise, verified before it's sold — and you can watch it behave right now. That's the whole catch.
